# quant-electronics

A 20-day learning journey combining **Quantitative Finance** and **Electronics** fundamentals.

## Repository Structure

```
quant-electronics/
├── README.md
├── 20_day_log.md        # Daily progress log
├── quant/               # Quantitative finance notebooks & notes
│   └── day01_ev_lln.ipynb
└── electronics/         # Electronics notes & projects
```

## Getting Started

- Open any `.ipynb` file in [Google Colab](https://colab.research.google.com/) to run interactively.
- Track daily progress in `20_day_log.md`.
